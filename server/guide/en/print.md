# Print

## What to do here

- Save the PDFs and print them anywhere, or print directly when the shared machine runs Linux.
- Print on A4 at 100% (actual size), never "fit to page".
- The exam locks after printing: questions and layout can no longer change.

## What this step is for

Getting the papers onto paper exactly as built, because AMC finds each box by its position on the page.

## How to do it

- **Save PDFs for printing**: download the papers and print them from any computer, for example from a pendrive.
- **Print on this machine**: send them to a printer connected to the shared machine. This needs a Linux shared machine where `./amc printer on` has been run.
- Choose which copies to print, then press the button.

Printing locks the exam. If the papers were printed another way, use **Mark as printed**.

## Common problems

**Pages aren't recognised after scanning.** The print was probably scaled. Print at 100% ("actual size"), with every corner mark fully on the paper.

**I need to print more copies.** Save or print the same papers again: they are identical. Copies beyond those built need a rebuild, which isn't possible once the exam is locked.

**A question must change after printing.** Unlock the exam in Questions or Papers. This removes scans and marks, and papers already printed will no longer match. Duplicating the exam is often the better choice.
